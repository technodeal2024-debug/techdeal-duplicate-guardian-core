# Owner-controlled public release checklist

**Do not make this repository public before these are complete.**

1. Obtain written authorization from the copyright/IP owner (including the Verma Traders proprietor if that business owns the code). Clarify TechDeal AI trademark ownership and accurate copyright attribution.
2. Perform secret, credential, personal-data and third-party-license review of the entire Git history. This project is independent original source; never transplant proprietary Android/Windows repositories, assets or their Git histories.
3. Verify the code works on your development PC, including Windows CI once uploaded.
4. Verify it contains ONLY standalone OSS core functionality and no private mobile/desktop application code, signing keys, credentials or client information.
5. Check CI and GitHub vulnerability features. Keep PRIVATE until owner explicitly approves making the exact reviewed revision PUBLIC.
6. Add repository topics: duplicate-files, python, privacy, open-source, file-hashing.
7. Create a tagged release v0.1.0 after CI passes and owner approves the release. Report honest limitations.
8. Maintain real issue/PR responses, tests, tagged releases and user documentation. Never create artificial stars or downloads.

The Codex for OSS program evaluates genuine established open-source maintainership and public adoption. A newly published repo alone does not establish eligibility or promise ChatGPT Pro.
